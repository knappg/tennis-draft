# Wimbledon 2026 draw toolkit

Regenerates `src/lib/data/wimbledon2026.ts` — the committed static draw used for the
`wimbledon-2026-atp` / `wimbledon-2026-wta` tournaments. The app reads only the generated
`.ts`; these scripts exist so you can rebuild it when the draw changes (withdrawals,
qualifier/lucky-loser swaps, a fresh ranking snapshot).

Why static: draft eligibility depends on a player's **seed**, and seeds can diverge from
live ranking (withdrawals shift the seed list; qualifiers/wildcards aren't top-ranked).
We source seeds from the official draws rather than deriving them from the API.

## Files

| File | What it is | Edit by hand? |
|------|------------|---------------|
| `draw-atp.json` / `draw-wta.json` | Official main draws. One string per entrant: `"Surname\|SEED"` (ATP) or `"A. Surname\|SEED"` (WTA). `SEED` is `1`–`32`, `Q`, `WC`, or omitted. Order **is true bracket order** — adjacent entries (1-2, 3-4, …) are round-1 matchups, so seeds 1/2 sit first/last. The set + seeds drive eligibility; the bracket pairing drives the "Plays {X}" first-round-opponent tags (display only). | **Yes** — this is the source of truth |
| `overrides.json` | Manual name resolutions for ambiguous surnames (e.g. Matteo vs Jacopo Berrettini) + `rankAlias` for ranking-dump name mismatches. Keys are 1-based draw positions. | Yes, as needed |
| `idmap.json` | Snapshot of RapidAPI player ids by name. Regenerated by `build-idmap.mjs`. | No (regenerate) |
| `build-idmap.mjs` | Refreshes `idmap.json` from RapidAPI rankings + Wimbledon feed. Needs `RAPIDAPI_KEY` in `.env`. | No |
| `generate.mjs` | Produces `src/lib/data/wimbledon2026.ts`. | No |

Live rankings (display only) come from `data/rankings-atp-2026-06-26.txt` and
`data/rankings-wta-2026-06-26.txt` — copy-paste dumps of
[live-tennis.eu](https://live-tennis.eu/en/atp-live-ranking). `data/` is gitignored, so
these live locally only; the ranking values get baked into the committed `.ts`. Players
missing from the dump simply show no ranking (`—`). The date is set by `RANKING_DATE` in
`generate.mjs`.

## Regenerate

```bash
# 1. (only if you need ids for new players) refresh the id snapshot
node scripts/wimbledon2026/build-idmap.mjs

# 2. rebuild the static draw
node scripts/wimbledon2026/generate.mjs

# 3. format
npx prettier --write src/lib/data/wimbledon2026.ts
```

`generate.mjs` validates as it runs (128 players/tour, unique ids, seeds 1–32 complete)
and **exits non-zero listing any unresolved entrant** — fix `overrides.json` (or refresh
`idmap.json`) and re-run. Then commit `wimbledon2026.ts`.

## Data provenance (2026-06-26)

- ATP draw: tennisexplorer.com (atptour.com blocks automated fetch)
- WTA draw: wtatennis.com
- Player ids + scoring: RapidAPI `tennis-api-atp-wta-itf` (same API the app syncs results from)
- Display rankings: live-tennis.eu dumps in `data/`
